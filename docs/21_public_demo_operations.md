# 临时公网演示操作说明

- 更新日期：2026-11-04
- 部署方式：本机 Streamlit + Serveo 免费 SSH HTTPS 隧道
- 适用范围：开题、答辩、评审临时查看
- 成本：0 元

## 1. 已确认的约束

- 所有知道网址的人都可以访问。
- 全部访客可以上传自己的 `.dem`。
- 使用访问口令限制入口。
- 单文件上限 1 GB。
- 最多 5 个并发解析任务。
- 每天最多 50 场解析任务。
- 使用用户提供的 DeepSeek API，访客无需自己的 API。
- 原始上传 Demo 解析完成后立即删除。
- 不使用本机离线大模型；模板保留为 API 故障兜底。
- 主要面向中国大陆网络，答辩期间使用。
- 服务器预算不超过 10 元；当前临时隧道方案成本为 0 元。

## 2. 启动

```powershell
cd D:\毕业设计
.\start_public_demo.ps1
```

脚本会：

1. 检查或启动本地 Streamlit。
2. 建立临时 HTTPS 公网隧道。
3. 输出公开网址。
4. 将运行状态保存在 `data/runtime/public_demo.json`。

访问口令保存在本地 `.env` 的 `APP_ACCESS_CODE` 中。

## 3. 停止

```powershell
.\stop_public_demo.ps1
```

停止后公网入口立即失效。

## 4. 重要限制

- 运行网页的电脑必须开机、联网且不休眠。
- 临时网址在隧道重新启动后会改变。
- 网络断开、电脑休眠或 SSH 隧道中断时，老师和学生将无法访问。
- 免费隧道不提供正式服务等级保证，不能视为永久部署。
- 当前访问口令不是完整账号系统，不适合大规模公开运营。

## 5. 答辩前必须测试

至少提前一天用另一台电脑或手机流量测试：

1. 公网网址能够打开登录页。
2. 输入访问口令后进入系统。
3. 固定 Nuke Demo 可以载入。
4. 可以选择玩家并生成真实 DeepSeek 报告。
5. 可以下载 Markdown、Word、PDF。
6. 关闭公网演示脚本后，网址失效。
