# AI 使用方式、他人访问与报告导出

- 更新时间：2026-11-04
- 已确认：MVP 使用 DeepSeek 云端，本地模板作为故障兜底

## 1. 当前推荐运行组合

```text
主路径：DeepSeek 云端 API
故障兜底：本地模板报告
```

DeepSeek 负责把真实结构化事实转化为更自然、更具体的教练式建议；
模板报告保证接口失败时系统仍能完成分析。

当前网页已经可以选择三种报告引擎。没有配置密钥或模型时，系统提示并自动使用模板。

## 2. DeepSeek 配置

不要把密钥发送到聊天、写入代码或提交 Git。

推荐在项目根目录创建 `.env`：

```text
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
LLM_TIMEOUT_SECONDS=60
```

网页启动时会自动读取 `.env`，然后可在侧边栏选择“DeepSeek 云端”。

## 3. 其他人使用网页时是否需要 API

### 情况 A：别人只是看你在同一台电脑上演示

不需要他们提供 API。网页使用服务器配置的 DeepSeek 密钥。

### 情况 B：网页部署在服务器，其他人通过网络访问

不需要每个用户自己的 API。推荐由网页维护者在服务器端保存一个 DeepSeek 密钥：

```text
访客浏览器
  -> 你的网页后端
  -> DeepSeek API
```

密钥只存在服务器环境变量中，不能写入浏览器 JavaScript 或公开源码。还需要增加：

- 访问控制或登录。
- 每日调用次数和费用上限。
- 请求超时、失败提示和模板降级。
- 隐私说明与数据删除策略。

当前 Streamlit 是本地原型，没有账号、限流和公网安全层，不适合直接公开给大量陌生人使用。

### 情况 C：别人下载代码并在自己电脑运行

他们可以：

- 配置自己的 DeepSeek API；
- 或只使用模板报告，不配置任何 API。

### 情况 D：完全不使用大模型 API

模板报告仍可工作，但语言灵活性和针对性低于大模型。

## 4. 当前项目建议

毕业设计答辩阶段优先使用：

1. 本地运行网页。
2. DeepSeek 云端生成 AI 复盘。
3. 手机热点提供网络。
4. 模板报告作为 API 异常时的备用方案。
5. 不正式开放陌生用户注册和公网调用。

如果以后确实需要多人使用，再增加服务端代理、账户、限流和费用控制，不改变当前分析流程。

## 5. Word 和 PDF 导出

网页报告页已经提供：

- Markdown。
- Word。
- PDF。

导出内容来自同一份已校验报告，避免格式间事实不一致。Word 和 PDF 已使用真实 42 回合报告完成生成和逐页渲染检查。

当前使用通用排版。学校论文/报告模板取得后，可在不改动分析逻辑的前提下替换封面、页眉页脚、字体、标题编号和页边距。
