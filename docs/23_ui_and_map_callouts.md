# 网页视觉重构与地图点位词典

- 更新日期：2026-11-04
- 目标：改善页面层级、报告可读性和国内玩家对地图点位的理解
- 技术范围：Streamlit、Plotly、SQLite 事实层和现有报告 Provider 接口

## 1. 视觉方向

采用深色战术分析工作台：

- 深蓝黑背景和橙色高亮，贴近《CS2》分析工具语义。
- 顶部显示 Demo 状态、玩家、地图和比分。
- 指标卡、地图、AI 教练摘要分区展示。
- 报告中使用不同边线区分事实、行为推断和训练建议。
- 原始证据编号默认折叠，避免干扰正文。
- 移动端窄屏下自动改为单列布局。

## 2. 页面结构

### 2.1 导入页

- 显示当前步骤和隐私说明。
- 上传 `.dem` 与公开演示样本放在同一主卡片。
- 明确 1 GB 上限、解析后删除和真实数据边界。

### 2.2 玩家分析

- 从真实玩家列表中选择一名玩家。
- 主按钮统一为“生成 AI 画像与复盘”。
- 报告引擎在侧边栏选择，DeepSeek 为优先项，本地模板为降级项。

### 2.3 教练总览

- 核心指标：击杀、首轮交火参与率、远离队友比例、队友接敌时就近比例。
- 左侧显示全场位置热区与逐回合路线。
- 右侧显示 AI 教练摘要和最多三个训练优先级。
- 回合时间线改为结构化表格。
- 队伍经济图默认折叠，按需查看。

### 2.4 位置、关键回合和单回合

- 位置页支持全场或单回合。
- 关键回合卡片合并同一回合的多个标签，避免重复。
- 单回合页依次显示地图、事件、回合经过、可观测影响和队友阵亡后的行动建议。

### 2.5 完整报告

- 事实、行为推断、训练建议使用不同颜色标识。
- 证据编号按 claim 折叠展示。
- 保留 Markdown、Word、PDF 下载。
- 原始 Markdown 放在折叠区，主要视图使用结构化卡片。

## 3. 地图点位词典

解析器输出的英文地点名保留在 SQLite 中，展示和报告阶段通过
`src/cs2_review/map_callouts.py` 转换为国内常用叫法。

重要约束：

- 每张地图使用独立词典，禁止跨地图混用。
- 未收录的地点回退显示原始解析名称。
- 地图区域映射和点位名称都属于项目规则资产，不是官方标准。
- LLM 事实包在发送前使用同一套中文点位名。
- 报告中的地点、路线和建议保持同一套叫法。

当前已覆盖：

- 远古遗迹 `de_ancient`
- 阿努比斯 `de_anubis`
- 炙热沙城 II `de_dust2`
- 炼狱小镇 `de_inferno`
- 荒漠迷城 `de_mirage`
- 核子危机 `de_nuke`
- 死亡游乐园 `de_overpass`

同时预留：

- 死城之谜 `de_cache`
- 列车停放站 `de_train`
- 殒命大厦 `de_vertigo`

## 5. 报告内容调整

DeepSeek 提示词新增：

- 使用温和、具体、行动导向的教练口吻。
- 减少重复的“系统判断”。
- 百分比直接写成百分数。
- 关键决策优先采用“发生了什么—影响—可以尝试”的顺序。
- 关键词使用事实包中的国内地图点位名。
- 不把证据编号重复粘进正文。
- 全场总结只保留最重要的三个问题和可执行训练动作。

## 6. 验证

本地检查：

- 页面访问口令和导入页可加载。
- 公有 Dust2 样本可进入玩家选择。
- 中文点位能够出现在路线表、关键回合和报告中。
- 模板降级报告可结构化显示。
- 地图路线和热区在深色主题中可见。

自动化测试覆盖：

- 地图点位中文化。
- 不同地图之间不会错误复用点位名。
- LLM 事实包保留字段结构并完成地点本地化。
- Streamlit 主流程。
- Word/PDF 导出。
