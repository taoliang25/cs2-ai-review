# 中国大陆直连部署方案

- 提出时间：2026-11-06
- 新增强制要求：访问者只使用中国大陆普通网络，不开启 VPN 或代理
- 当前结论：`*.streamlit.app` 不满足最终演示要求，只保留为备份
- 项目代码：保留现有 Streamlit 网页、Demo 解析和 DeepSeek 分析逻辑

## 1. 需求边界

最终地址必须满足：

- 浏览器直接输入网址即可打开。
- 中国大陆普通宽带、手机热点或学校网络无需 VPN。
- 访客不安装 Python、Git 或项目依赖。
- 使用维护者的 DeepSeek API。
- 通过访问口令控制访客。
- 支持上传单场 Demo。
- 原始文件分析后立即删除。
- 不要求用户自己的服务器和自有域名。

## 2. 为什么更换 Streamlit Community Cloud

现有地址：

`https://cs2-tactical-review-taoliang25.streamlit.app`

该地址可以完成系统功能，但用户已实测必须开启 VPN 才能进入，因此不能作为
最终答辩地址。公网部署平台的选择必须服从“国内直连”这一硬性条件。

## 3. 候选平台

### 3.1 魔搭 ModelScope 创空间（优先核验）

优点：

- 阿里巴巴旗下国内平台。
- 提供国内访问的创空间页面。
- 提供在线 AI 应用托管入口。
- 可使用平台分配地址，不需要自有域名。
- 对少量毕业设计演示更合适。

需要实际核验：

- 当前创空间是否直接支持 Streamlit SDK。
- Python 3.13 和 Awpy/demoparser2 依赖能否安装。
- 免费 CPU、内存和磁盘能否解析目标 Demo。
- 公网应用是否禁止访问 DeepSeek API。
- Secrets 的配置方式。
- 1 GB 上传和长时间请求限制。
- 休眠策略。

如果平台只支持 Gradio，可将现有 Streamlit 页面迁移到 Gradio，但分析、数据库、
规则、DeepSeek 和导出模块保持不变。是否迁移界面框架必须根据平台实际限制决定。

### 3.2 阿里云或腾讯云容器/云服务器

优点：

- 国内网络访问通常更稳定。
- 可完整运行 Streamlit 和 WebSocket。
- 文件上传、超时和依赖限制更可控。

缺点：

- 需要实名账号和云端配置。
- 免费或低预算资源可能只有短期额度。
- 需要额外处理访问控制、HTTPS、进程守护和清理。
- 10 元预算可能只够短期低配实例。

适用条件：用户接受短期云资源，且没有域名时允许使用平台公网 IP 或临时域名。

### 3.3 Hugging Face Spaces

不作为首选：

- 国内直连是否稳定仍需用户实测。
- 与“必须国内普通网络访问”的要求不匹配的风险较高。

### 3.4 本地内网穿透

不作为最终方案：

- 需要用户电脑持续开机。
- 免费域名和隧道容易被拦截。
- 不适合老师在自己的电脑上长期访问。

## 4. 迁移原则

不需要重写：

- Demo 解析。
- SQLite 事实层。
- 行为指标和可解释规则。
- 关键回合。
- DeepSeek 报告。
- 证据校验。
- 模板降级。
- Markdown/Word/PDF 导出。

可能调整：

- 云端入口和进程启动方式。
- Secrets 配置。
- 文件与临时目录位置。
- 上传大小和超时。
- 平台不兼容 Streamlit 时的前端实现。

## 5. 迁移验收流程

1. 使用普通国内网络、完全关闭 VPN。
2. 打开平台公网地址。
3. 输入访问口令。
4. 载入内置小样本。
5. 选择玩家并生成 DeepSeek 报告。
6. 下载 Markdown、Word 和 PDF。
7. 用手机流量再次打开。
8. 用另一台电脑和学校网络访问。
9. 测试 1 GB 文件；若平台限制，记录真实上限，不虚报支持能力。
10. 只有国内直连浏览器实际成功后，才替换 Streamlit Cloud 地址。

## 6. 当前必须确认的问题

部署到魔搭或云平台需要用户本人的平台账号授权。代码无法代替注册、实名、
登录和授权。

当前最关键问题：

**用户是否已有魔搭 ModelScope 账号（可通过手机号或第三方账号登录），并愿意
用该账号部署本项目？**

如果已有，下一步进行：

1. 登录魔搭。
2. 验证创空间是否支持 Streamlit。
3. 创建私有代码仓库或关联现有 GitHub 仓库。
4. 配置 DeepSeek Secrets。
5. 部署并关闭 VPN 实测。

如果用户没有账号，需要先由用户本人注册；注册和实名等账号步骤不能由 AI 代办。
