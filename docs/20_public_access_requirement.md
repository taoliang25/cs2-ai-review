# 公网访问需求

- 提出时间：2026-11-04
- 状态：已理解需求，等待确认访问和资源约束
- 已确认目标：任何电脑通过浏览器输入网址即可打开网页使用，不依赖项目电脑上的 `localhost`

## 1. 需求含义

目标部署形态：

```text
任意电脑浏览器
  -> HTTPS 公网网址
  -> 网页前端
  -> Demo 解析与分析服务
  -> DeepSeek / 本机模型或模板报告
  -> 在线结果与 Markdown/Word/PDF 下载
```

现有需求不变：

- 单场 Demo。
- 单个主要分析玩家。
- 真实事件与证据。
- 复盘与训练建议。
- 本地保底报告。

需要改变的是运行位置、文件存储、并发处理、密钥管理和安全措施。

## 2. 公网运行必须新增的能力

### 2.1 稳定公网地址

- 需要域名或平台分配的 HTTPS 地址。
- 用户不需要安装 Python、Streamlit 或解析库。
- 网页需要能在无人值守状态下启动。

### 2.2 服务器端 Demo 上传与临时存储

Demo 不再只存在用户自己的电脑，而会先上传到运行网页的服务器。

需要确定：

- 单文件大小上限。
- 文件保留多久。
- 是否在报告生成后立即删除。
- 是否需要加密存储。

首版建议分析完成后立即删除原始 Demo 和临时数据库，不提供历史记录。

### 2.3 服务器端 DeepSeek 密钥

用户不需要看到密钥。推荐：

```text
访问者浏览器 -> 你的服务器 -> DeepSeek API
```

不能把密钥写进网页前端代码。服务器密钥被公开后，任何人都可以消耗你的额度。

### 2.4 并发与资源限制

当前本地流程会：

- 读取最大 2 GB 的 Demo。
- 建立约数十 MB 的 SQLite。
- 解析数秒到数十秒。
- 生成多个图表和报告。

免费云服务常见的内存、CPU、磁盘和请求时长限制可能不足以同时处理多个大 Demo。需要明确演示人数和并发量。

### 2.5 隐私与安全

公网用户上传的文件可能包含：

- 玩家名称。
- Steam ID。
- 对局聊天和事件。
- 用户个人游戏记录。

至少在页面上增加：

- 文件用途和删除说明。
- 是否发送去标识化摘要给 DeepSeek 的提示。
- 用户确认后才能调用外部模型。
- 上传大小和格式限制。
- 调用次数限制。
- 服务端错误日志清理机制。

### 2.6 文件清理

公网环境不能无限累积 Demo。建议每次分析使用独立临时目录，并在：

- 报告生成完成后；
- 用户主动删除后；
- 定时任务发现过期后；

删除原始 Demo、SQLite 和导出缓存。

## 3. 可选部署方案

### 方案 A：最小公网 Demo

- 平台提供一个公开 HTTPS 地址。
- 固定公开完整 Demo 可直接体验。
- 只允许少量授权用户上传。
- 单次只允许一个分析任务。
- 上传上限暂时较小。
- 服务器持有 DeepSeek 密钥。

适合开题和答辩，开发风险最低。

### 方案 B：直接公网自助使用

- 任何人打开网址后可上传 Demo。
- 服务器处理、生成报告并自动删除文件。
- 需要访问限制、限流、任务隔离和资源监控。
- 需要更可靠的计算资源和预算。

工程量和运维风险明显高于方案 A。

### 方案 C：公网展示 + 私人分析

- 公开页面展示固定 Demo 和系统能力。
- 用户自己的 Demo 需要访问口令或登录后上传。

适合毕业设计：老师或评审无需安装环境即可访问，同时控制文件与 API 成本。

## 4. 当前代码需要调整的部分

当前代码已复用，不需要重写分析核心：

- 网页 UI 可从本地流运行迁移到云端。
- Demo 上传目录应改为临时工作目录。
- SQLite 应放在每次任务的临时目录。
- DeepSeek 密钥改为服务器环境变量。
- 原始文件、SQLite 和导出文件增加生命周期清理。
- 增加并发锁或任务队列。
- 增加公网访问控制、速率限制和费用上限。
- 增加健康检查和错误日志。

如果继续使用 Streamlit Community Cloud，需要先验证平台的上传大小、内存、持久连接和休眠政策。该类免费平台通常不适合承诺随时在线或处理 2 GB 大文件。稳定公开访问更可能需要一台有固定资源的云服务器或容器平台。

## 5. 需要用户确认

### 5.1 用户已确认

- 所有知道公网网址的人都可以访问。
- 所有访客都可以提交自己的 Demo。
- 分析完成后立即删除上传文件。
- 单文件最大 1 GB。
- 最多 5 人同时使用，每天最多约 50 场。
- 主要从中国大陆访问。
- 接受少量服务器费用，学校不提供服务器。
- 没有域名，接受平台提供网址。
- DeepSeek 费用由用户统一承担，目前表示不设金额上限。
- 如果网络始终可用，希望从 MVP 中移除本机离线大模型。

### 5.2 必须澄清的技术限制

远程网页不能直接读取访问者电脑上的任意绝对路径。例如：

```text
用户电脑：D:\CS2\my_match.dem
部署服务器：读取不到该路径
```

这不是当前代码限制，而是浏览器安全边界。可行的远程流程是：

1. 用户点击网页的“选择 Demo”。
2. 浏览器把该 `.dem` 上传到服务器临时目录。
3. 服务器解析和生成报告。
4. 分析完成后立即删除原始 Demo 和临时数据库。

如果必须输入本地绝对路径，只能在网页和 Demo 位于同一台电脑时使用，
无法满足“从任意电脑打开网址”的要求。

### 5.3 推荐调整

- 从首版删除“本机兼容模型”入口，保留 DeepSeek 云端。
- 保留确定性模板作为 DeepSeek 超时、故障或输出校验失败时的安全兜底；
  它不是本机大模型，不增加离线模型部署成本。
- 网页公网部署，DeepSeek 密钥仅保存在服务器环境变量。
- 采用上传文件方式，不使用用户本地路径。
- 分析任务使用独立临时目录，结束后立即删除。
- 即使不限制 API 费用总额，也要设置技术性限流和单请求上限，
  避免公开网址被恶意刷取额度。

### D1. 公开范围

“任何电脑可以打开网址”具体是：

- A. 知道网址的人都可以访问。
- B. 只给导师、同学或评审访问，需要简单访问口令。
- C. 真正公开给所有互联网用户。

### D2. 上传权限

- A. 所有访客都能上传自己的 Demo。
- B. 只有你授权的人可以上传。
- C. 公网页面只展示固定 Demo，私人分析仍需口令。

### D3. Demo 文件保留

- A. 分析完成后立即删除（推荐）。
- B. 保留 24 小时后删除。
- C. 需要长期保存和查看历史。

### D4. AI 方式

- A. 使用你服务器端的一份 DeepSeek 密钥，访客不配置 API（推荐）。
- B. 每个访客自己填写 API。
- C. 服务器端 DeepSeek + 本机模型同时可用。

### D5. 访问量

- 预计同时使用人数：1 人 / 2–5 人 / 10 人以上。
- 预计每天分析场数：1–5 / 6–20 / 20 以上。

### D6. 文件大小

必须支持的最大 Demo 大小：

- A. 300 MB。
- B. 1 GB。
- C. 2 GB。

### D7. 在线要求

- A. 只有演示时需要在线。
- B. 全天都能打开。
- C. 需要较可靠的服务承诺。

### D8. 访问地区

- A. 主要在中国大陆访问，不能依赖 VPN。
- B. 国内外都需要。
- C. 学校网络或特定地区即可。

### D9. 可用预算

- A. 只使用免费服务。
- B. 可以接受少量月度服务器费用。
- C. 学校能提供服务器或云资源。

### D10. 前端功能

- 是否需要登录？
- 是否需要保存报告？
- 是否允许访客看到其他历史报告？

### D11. DeepSeek 费用

- 谁能使用你的 API 额度？
- 是否设置每日调用次数上限？
- 是否只在生成报告时调用一次？

### D12. 个人 Demo

- 其他人能否上传包含真实玩家名和 Steam ID 的 Demo？
- 是否允许服务器暂时保存这些文件？
- 是否需要自动匿名化报告？

## 6. 当前推荐方案

在未获得进一步回答前，建议采用：

- 公网部署。
- 固定完整 Nuke 赛事 Demo 可公开体验，同时所有访客可上传自己的 Demo。
- 不启用本机模型，DeepSeek 作为唯一生成式 AI；模板仅做故障兜底。
- 上传文件分析后立即删除。
- DeepSeek 由服务器统一调用，访客不接触密钥。
- 单次任务、每日任务和文件大小设置技术上限。
- 默认模板报告兜底。
- 首版不开放陌生人注册和永久历史记录。

## 7. 临时答辩部署工具

项目已增加：

- `start_public_demo.ps1`：启动本地网页和免费 HTTPS 临时隧道。
- `stop_public_demo.ps1`：停止当前项目启动的网页和隧道进程。

该方式成本为 0 元，适合答辩时临时使用，但要求项目电脑持续开机、
联网且不休眠。公网网址和访问口令不应长期公开传播。

该方案能满足“任何电脑输入网址即可使用”，同时控制隐私、成本与运维风险。
