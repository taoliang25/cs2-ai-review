# 数据库设计

- 数据库：SQLite
- 首版策略：每场 Demo 一个逻辑分析记录，本地保存；不要求账户和云端历史
- 数据文件：默认 `data/processed/<demo_sha256前12位>.sqlite`
- 原始 Demo、数据库和中间数据均不提交 Git

## 1. 设计原则

1. 原始事实与派生指标分开保存。
2. 事件和指标均带稳定证据 ID。
3. 规则/模型版本必须可追溯。
4. 玩家以 Steam ID 作为技术主键，显示名单独保存。
5. 大模型报告不覆盖事实数据。
6. 不使用当前数据库结构冒充最终论文定稿，真实解析后可按字段证据调整。

## 2. 实体关系概览

```text
analysis
  |-- player
  |-- round
  |-- tick_sample
  |-- game_event
  |-- round_player_metric
  |-- match_player_metric
  |-- key_round
  `-- report
```

## 3. 表说明

### `analysis`

一场 Demo 的一次分析运行。

- Demo 哈希、路径、地图、回合数、tick rate 和播放时长。
- `has_match_end` 标记是否观察到 `cs_win_panel_match`；没有该事件时提示可能是片段。
- `regulation_complete` 进一步要求比赛结束且任一方胜场达到 13；
  它用于识别完整常规对局，不能替代实际模式核验。
- 解析器名称、版本和状态。
- 失败原因和运行时间。

### `player`

本场解析出的真实参赛玩家。

- Steam ID。
- 当前显示名和起始阵营。
- `is_recorder` 标记，用于排除 `DemoRecorder`。
- 解析时还会排除 `m_iCoachingTeam` 非零的教练和 `spectator`，只保留
  `terrorist`、`counter-terrorist` 身份。

### `round`

由解析器得到的回合边界与结果。

- 回合序号。
- 开始、冻结结束和结束 tick。
- 获胜方、结束原因和原因名称。

### `tick_sample`

玩家位置和状态的时间采样。

- 默认每秒一个采样点。
- 保存世界坐标、地图当前位置名称、视角、生命、护甲、现金、装备和被包等状态。
- 先保存世界坐标，雷达坐标在分析层按地图版本换算，避免破坏原始事实。

### `game_event`

关键事件的统一证据表。

- 事件类型、回合、tick、行动者、目标和武器。
- 世界坐标。
- 原始补充字段存为 JSON。
- `evidence_id` 可被指标和报告引用。

### `round_player_metric`

某玩家某一回合的派生指标。

- `metric_key`、数值、文本值、单位。
- 样本量、置信/完整度、规则版本。
- 证据 ID 列表。

### `match_player_metric`

某玩家整场聚合指标。

- 与回合指标相同的版本和证据约束。
- 适用于开局路线偏好、跟队率、残局表现等全场画像能力。

### `key_round`

优秀回合、问题回合、高影响回合或代表性回合。

- 类别、排名分数和入选理由。
- 对应证据 ID。
- 排序贡献项保存在 JSON 中。

### `report`

事实包生成的复盘报告。

- 模板或大模型 Provider。
- 提示词/模板版本。
- 事实包哈希，保证报告可追溯到输入。
- 生成状态、结构化 JSON 和可展示 Markdown。

## 4. 数据与版本约束

- 同一 `demo_sha256` 首版只创建一个主分析记录。
- 玩家表不把显示名当作唯一身份。
- 指标以 `(analysis_id, steamid, metric_key, rule_version)` 区分。
- 关键回合必须至少关联一个证据或明确标注“由人工选择”。
- 报告必须记录 `fact_bundle_sha256`，不能只保存最终文本。
- 删除 Demo 后不应自动删除已经生成的论文实验结果，应由独立清理流程处理。

## 5. 坐标与地图版本

- 原始坐标保持解析器输出。
- 地图世界坐标到雷达坐标的转换参数需记录地图名称和地图数据版本。
- 区域多边形属于项目规则资产，必须保存区域版本。
- 热力图聚合使用的网格大小和采样方式需写入指标元数据。

## 6. 索引

至少为以下查询建立索引：

- 按分析记录和回合查询事件。
- 按玩家、回合和 tick 查询采样。
- 按玩家和指标查询全场指标。
- 按分析记录和玩家查询关键回合。
- 按分析记录和玩家查询报告。

完整建表语句见 `database/schema.sql`。
