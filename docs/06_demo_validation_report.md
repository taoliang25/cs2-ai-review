## 4. 字段覆盖

### 4.1 玩家与回合

已验证：

- Steam ID、显示名、阵营。
- 回合开始、冻结结束、结束 tick。
- 获胜方、结束原因和原因名称。

### 4.2 位置与状态

Awpy 逐秒快照已验证可返回：

- 世界坐标、速度和视角。
- 生命、护甲、头盔、拆弹器和携带炸弹状态。
- 主动/主/副武器、库存和投掷物数量。
- 现金、装备价值和回合初装备价值。
- 蹲、走、跳、瞄准镜、装弹、拆弹和被闪状态。

单场全场逐秒快照约 9,036 行、40 列，可支撑轨迹和热力图。

### 4.3 事件与目标

已验证可返回：

- 击杀、伤害、助攻和交易关系。
- 武器、爆头、穿烟和穿墙等信息。
- 炸弹拾取、掉落、开始安放、安放完成和站点。
- 投掷物轨迹、烟雾持续、火焰起止和射击位置。
- 回合经济与购买类型。

## 5. 当前验证结论

### 结论一：技术路线可行

当前电脑能够稳定解析具有常规 5v5 结构的 CS2 Demo，且关键事实层所需字段基本齐备。

### 结论二：Awpy 更适合作为主解析器

Awpy 的领域数据表更贴近项目需求，位置、经济、装备和投掷物可直接用于指标计算与可视化。

### 结论三：仍需完整正式样本

公开测试样本可用于开发，但不能证明所有普通玩家的完整竞技或 Premier Demo 都同样可用。最终系统必须在用户本人参与的完整 Demo 上重新验收。

### 结论四：当前没有准确率结论

本次只验证了解析和字段，不涉及战术标签或模型效果，因此不能从本次结果得出任何“识别准确率”。

## 6. 需要继续验证

- 多场不同地图、胜负和比分长度的常规 5v5 Demo。
- 常规玩家生成 Demo 与 SourceTV/平台 Demo 的字段差异。
- 地图雷达坐标的视觉对齐。
- 回合开始前和半场交换阵营的处理。
- 用户最终 Demo 的解析耗时、内存和失败恢复。
