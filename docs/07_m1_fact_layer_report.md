## 3. 已验证的指标

对其中一名测试玩家完成了以下真实计算：

- 击杀、死亡和助攻。
- 每回合首轮交火参与、首杀和首死。
- 最近存活队友距离及近队/远离队友比例。
- 领先局与落后局中的远离队友比例。
- 队友首次交战时的距离和之后 5 秒内的战斗参与。
- 最后存活残局回合。
- 主要活动地点和每回合首次离开出生区地点。
- 道具购买、烟雾/燃烧效果、闪光致盲和道具伤害。
- 每回合可解释影响分数、优秀回合和问题复盘候选。

## 4. 重要口径与限制

- 测试玩家的具体数值只用于验证代码执行，不作为论文结论。
- “远离队友”是空间距离规则，不等于主观单走。
- “问题回合”是优先复盘候选，不等于已证明玩家失误。
- 道具购买数不等于实际投掷数。
- 闪光致盲和伤害效果会遗漏完全无效的投掷。
- 同一 tick 多事件顺序可能无法唯一确定。
- 位置按 1 秒采样，快速交战中的精确距离可能存在误差。
- 当前样本仅 10 回合且以投降结束，不用于证明长期打法或泛化能力。
