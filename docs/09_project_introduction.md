# 项目简介

## 开题材料版

随着电子竞技训练逐渐由经验驱动转向数据驱动，如何帮助普通《CS2》玩家理解个人决策、发现稳定行为习惯并转化为可执行的改进方案，成为赛后复盘中的实际问题。传统对局统计主要呈现击杀、死亡、伤害和评分等结果指标，难以说明玩家开局去了哪里、是否与队伍保持协同、何时主动发起交火，以及关键操作如何影响回合局势。

本课题拟设计并实现“基于对局事件的《CS2》战术识别与赛后智能复盘系统”。系统面向《CS2》常规 5v5 单场 Demo，用户上传比赛文件后，可从解析出的真实玩家列表中选定一名主要分析对象。系统将围绕该玩家的位置轨迹、交战、道具、经济和目标事件，计算开局路线、区域偏好、跟队或独立行动倾向、首杀尝试、优势与劣势局差异、支援行为以及残局处理等可解释指标；在此基础上筛选优秀回合、问题复盘回合和高影响回合，展示位置图、热力图、经济变化和事件时间线。

系统拟采用事件驱动的分层分析方案：先使用 Demo 解析库提取真实结构化事实，再通过规则和统计方法计算行为特征、识别战术模式与关键回合，最后将结构化事实包交给可替换的大模型生成通俗复盘。为避免大模型编造比赛过程，报告内容将受到事实范围、证据编号和输出格式约束，并明确区分可观测事实、行为推断与改进建议；当大模型不可用时，系统可使用模板报告完成降级运行。网页端计划采用本地部署方式，形成“上传单场 Demo—选择单个玩家—生成全场画像—查看关键回合—获得训练建议”的完整闭环。

本课题的预期成果包括可运行的个人复盘网页原型、结构化对局数据与行为指标、证据驱动的智能报告生成流程，以及真实解析和实验验证材料。研究重点不在于简单复现比赛统计数据，而在于将分散的对局事件转化为可核验、可解释、能够指导玩家改进的行为证据，并为单场电子竞技对局的行为分析与智能复盘提供一种清晰、可复现的实现思路。

## 400 字精简版

传统《CS2》赛后统计主要关注击杀、死亡和评分，难以解释玩家的路线选择、团队协同和关键决策对局势的影响。本课题面向常规 5v5 单场 Demo，设计并实现基于对局事件的《CS2》战术识别与赛后智能复盘系统。用户上传一场比赛后，可选择一名主要分析玩家，系统根据真实位置、交战、道具、经济和目标事件，计算开局路线、区域偏好、跟队倾向、首杀尝试、支援行为、优劣势局差异和残局处理等指标，并生成玩家画像、关键回合、单回合分析及训练建议，同时展示位置热力图、经济变化和事件证据。

系统采用“真实事件提取—行为特征计算—关键回合识别—证据约束报告”的技术路线。大模型仅基于结构化事实生成解释，并需引用证据，避免脱离比赛内容编造；无大模型接口时使用模板报告降级。最终形成“上传单场 Demo—选择单个玩家—生成有证据的复盘报告”的本地网页原型。预期成果包括可运行系统、结构化数据、可解释指标、智能报告流程和真实验证材料，可为普通玩家理解个人打法并改进关键决策提供支持。

## 一句话简介

本项目面向《CS2》常规 5v5 单场对局，从真实位置与事件数据中识别单个玩家的行为倾向和关键决策，并通过证据可核验的网页报告帮助玩家发现打法问题、理解决策影响并获得训练建议。

## 答辩口头介绍

我的课题是做一套《CS2》个人赛后智能复盘系统。玩家上传一场常规 5v5 Demo，选择自己以后，系统先解析真实的位置、击杀、伤害、道具、经济和目标事件，再计算他常用的开局路线、区域偏好、跟队倾向、首杀尝试、支援行为和残局处理方式。系统会从这些真实指标中挑选优秀回合和值得改进的回合，并在地图热力图、经济曲线和事件时间线上展示证据。最后由大模型把结构化事实转成容易理解的复盘与训练建议，但大模型不能编造比赛内容；如果接口不可用，也能用模板报告完成分析。这个项目的重点不是再做一个 K/D 评分工具，而是让玩家不仅知道结果，还能理解自己的选择怎样影响了回合。
