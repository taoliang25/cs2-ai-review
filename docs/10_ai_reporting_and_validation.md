# AI 复盘与证据校验

- 文档版本：v0.1
- 更新日期：2026-11-04
- 当前状态：Provider、去标识化、输出校验与模板降级已实现；尚未真实调用外部大模型

## 1. 工作流程

```text
真实 Demo
  -> SQLite 事实层
  -> 行为指标与关键回合
  -> FactBundle
  -> 去标识化、缩减证据包
  -> OpenAI-compatible API
  -> JSON 结构校验
  -> 证据 ID 与回合编号校验
  -> Markdown 报告
  -> 保存 report 表
```

任何一步失败时，系统使用确定性模板报告完成闭环。

## 2. 事实包

完整 FactBundle 用于本地展示和审计，包含：

- 对局与玩家基本身份。
- 已计算指标、定义、样本量和置信度信息。
- 每回合行为与结果。
- 关键回合及评分分量。
- 事件、轨迹采样和支援上下文的证据 ID。

## 3. 外部模型输入

启用大模型后，系统不会发送原始 Demo、玩家名称、Steam ID、原始坐标或完整枪击事件。发送内容包括：

- 地图、回合数和比分。
- 目标玩家的匿名化行为指标。
- 每回合聚合结果。
- 关键回合候选。
- 去标识化的事件摘要。
- 允许引用的证据 ID 列表。

当前最多选择 80 条证据，优先保留优秀、问题和关键影响回合的事件。

## 4. 输出结构

模型必须输出六个章节：

1. 本场玩家画像。
2. 回合时间线。
3. 关键决策分析。
4. 单回合复盘。
5. 全场总结与训练建议。
6. 证据展示。

每条 claim 必须声明类型：

- `observation`：可观察事实，必须引用证据。
- `inference`：基于事实的行为推断，必须引用证据。
- `recommendation`：赛后建议，不冒充唯一正确答案。

## 5. 自动校验

系统拒绝以下输出：

- 缺少必需章节或章节为空。
- 引用事实包之外的证据 ID。
- 事实或行为推断没有证据。
- 引用不存在的回合编号。
- 声称百分之百还原想法、读取真实心理等读心表述。
- 顶层结果不是合法 JSON。

校验失败时，系统不展示 LLM 文本并改用模板报告。

## 6. 配置

当前 MVP 使用 DeepSeek 云端 Chat Completions 接口。

### 6.1 DeepSeek 云端

推荐在本机创建 `.env` 文件（该文件已被 Git 忽略），内容如下：

```powershell
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
LLM_TIMEOUT_SECONDS=60
```

也可以使用 PowerShell 环境变量。网页启动时会读取 `.env`。

### 6.2 通用兼容变量

`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` 仍作为通用兼容方式保留。网页优先使用上述 DeepSeek 或本机专用配置。

如果供应商不支持 `response_format`，系统可从文本中解析 JSON，并执行同一验证。

密钥不得写入源码、数据库或 Git。模板 `.env.example` 只含空占位符。

## 7. 当前验证范围

已验证：

- 玩家名、Steam ID 和坐标不出现在模型输入中。
- 合法 JSON 报告能够生成 Markdown。
- 虚假证据、读心表述和缺失章节会被拒绝。
- 模板报告在没有 API 时依然可用。

尚未完成：

- 当前电脑已确认用户拥有 DeepSeek API，但项目进程尚未读取密钥，因此尚未完成真实调用。
- 多模型事实一致率、可读性与成本实验。
- 学校或导师对 API 和隐私限制的确认。

在获得明确许可和 API 配置前，网页默认使用本地模板报告。

## 8. 其他人使用网页时是否需要 API

有三种模式：

1. **服务提供者持有密钥：** 用户不需要自己的 API。部署者把密钥保存在服务器环境变量中，网页只调用后端代理；适合最终演示。必须在服务器端设置访问控制、调用次数和费用上限，不能把密钥写进前端代码。
2. **用户自带密钥：** 每个使用者配置自己的 API。适合少量可信用户，但会增加操作和密钥管理风险。
3. **模板报告：** 不调用任何大模型 API，但建议的针对性会降低。

当前 Streamlit 是本地单机原型。若仅在自己的电脑上运行，用户只需要配置本机环境变量。若以后开放给其他人访问，推荐由服务器统一持有 DeepSeek 密钥，而不是让访客直接接触密钥。

完全不配置 API 或本地模型时，用户仍可使用模板报告，但模板的建议丰富度低于大模型。
