# 规则阈值敏感性实验

- 实验日期：2026-11-04
- 样本：当前公开授权的单场 `de_mirage` 测试 Demo
- 输出：[实验 JSON](../experiments/results/sensitivity_20261104T090045Z.json)、[距离明细 CSV](../experiments/results/sensitivity_distance_20261104T090045Z.csv)
- 当前规则版本：`event-rules-v0.1`、`tactical-rules-v0.2`

## 1. 目的

检查现有距离和早期路线阈值改变后，规则结果是否发生明显变化。该实验用于说明参数稳定性，不代表寻找“最优准确率”。

## 2. 队友距离敏感性

对 10 名玩家汇总，表中比例是先对每名玩家计算比例，再取玩家平均值。

| 最近队友距离阈值 | 较近队比例均值 | 玩家范围 |
|---:|---:|---:|
| ≤300 | 50% | 38%–63% |
| ≤400 | 54% | 42%–68% |
| ≤500 | 58% | 48%–73% |
| ≤600 | 62% | 52%–77% |
| ≤700 | 66% | 56%–82% |
| ≤800 | 71% | 59%–87% |

| 最近队友距离阈值 | 远端比例均值 | 玩家范围 |
|---:|---:|---:|
| >600 | 38% | 23%–48% |
| >700 | 34% | 18%–44% |
| >800 | 29% | 13%–41% |
| >900 | 24% | 7%–37% |
| >1000 | 21% | 4%–33% |
| >1200 | 15% | 2%–26% |

结果说明：

- “跟队/单走”结论对距离阈值敏感。
- 报告必须展示阈值和计算口径，不能只给“喜欢单走”的绝对结论。
- 当前 500/800 双阈值适合作为初始规则，但尚不能证明为最优参数。

## 3. 早期路线窗口敏感性

比较 5、10、15、20、25、30 秒窗口：

| 窗口 | 主导首次地点一致率均值 | 玩家范围 |
|---:|---:|---:|
| 5 秒 | 95% | 75%–100% |
| 10 秒 | 80% | 56%–100% |
| 15 秒 | 80% | 56%–100% |
| 20 秒 | 80% | 56%–100% |
| 25 秒 | 80% | 56%–100% |
| 30 秒 | 80% | 56%–100% |

该结果说明在当前样本中：

- 玩家通常较早离开出生区。
- 5 秒后继续延长到 15–30 秒时，主导地点结果基本不再变化。
- 不能据此认为所有地图和节奏下都稳定。

## 4. 解释边界

- 只有一场 Demo、一种地图和一种比赛局势。
- 没有人工标签，因此不能计算阈值分类准确率。
- 参数变化导致的规则比例变化，不等于模型性能变化。
- 后续需要在多个完整 Demo 上重复实验，并做玩家级、地图级分层比较。
