# Map Visualization Assets

These radar images and coordinate metadata were obtained from the public
Awpy data release `2000940`, matching the local CS2 map-coordinate version used
by the project.

Source:

https://github.com/pnxenopoulos/awpy-data/releases/tag/2000940

The files are used only to align in-game world coordinates with map layouts in
the educational review prototype. Do not represent these assets as original
project artwork.
